# Bank & Belege – Referenzdesign

Die Bankübersicht verwendet die kompakte, freigegebene Referenzdarstellung mit gruppierten Buchungszeilen, kontextbezogenen Buchungsicons, Status-Badges, kompakter Importstatus-Anzeige und eigener Buchungsdetailansicht.

Das ausführliche Importprotokoll wird nicht mehr dauerhaft zwischen Summenkarten und Buchungsliste angezeigt, sondern nur auf ausdrücklichen Abruf.
